Uso interno
Cómo se usan. Cada módulo es una página sin menú ni enlaces al resto de esta web, pensada para ir dentro de un <iframe>. Se adapta al ancho de la columna y al móvil. El código siempre apunta al recuento real: el desplegable de abajo solo cambia la vista previa de esta página. El código «sin script» fija una altura para escritorio y otra para móvil; si el contenido crece (más candidaturas, o al desplegar la lista de provincias) aparece una barra de desplazamiento dentro del módulo. El código «con script» estira el iframe hasta el alto exacto del contenido. Vuelven a pedir los datos cada dos minutos (?refresco=120, mínimo 30 segundos). Los textos de las páginas (título, entradilla y explicación) están en TEXTOS_ONDACERO_29N.md, en la repo.
