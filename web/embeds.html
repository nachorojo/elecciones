Código para el CMS y textos de los artículos · se actualizan solos con cada envío de Interior

Uso interno
Cómo se usan. En el CMS: Contenidos › Html › Crear. El código «web» va en el campo Html y el «AMP» en el campo Html AMP (hace falta si el módulo va dentro de un artículo, porque los artículos tienen versión AMP en móvil). Después se inserta en la noticia con el botón «Módulo HTML». El código normal apunta siempre al recuento real. Los botones ámbar copian el mismo código con datos de prueba, para ver cómo queda en un borrador: ese no se publica. El desplegable de abajo solo cambia la vista previa de esta página.
